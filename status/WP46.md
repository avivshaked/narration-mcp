## Decisions made (and why)
- **Recommended the static report**: no socket (the design's §0 item 11 and §17.1 stand), no new dependency,
  about half the effort; the cost is freshness, which question 1 puts to the owner.
- **A separate read-only reader is required for either option** (KNOW): opening a `NarrationStore` runs a
  write transaction and changed the database file in the probe, it creates a missing store, and its `get_*`
  reads delete rows whose files are gone.
- **The probe lives in the document's appendix, not in `spikes/`**, because this step adds documents only;
  WP46-A turns it into a test.
- plan.md and HANDOFF.md are the lead's files and were not edited. No CHANGELOG line: nothing a user of the
  package would notice has changed.
