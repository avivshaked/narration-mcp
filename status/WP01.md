## Decisions made (and why)
- The seed's byte layout (§10.3 leaves the concatenation open): UTF-8 parts joined by NUL, digest bytes
  0–3 big-endian, masked to 31 bits (interfaces.KeyBuilder).
- Keys carry schema ids the design does not name (`narration.delivery-key/v1`,
  `narration.analysis-key/v1`, `narration.measurement-key/v1`), so every hashed object is versioned.
- The engine profile hash excludes `snapshot_dir` (a local path), `observed` and `canary` (DC-3).
- `Hint.note` added (§9.1 lists it); it enters no key.
- The voice profile drops jitter/shimmer for CPPS (DC-1); speaking rate is null without a transcript.
- A failure inside a tool call is an `INTERNAL` tool error; -32603 only outside one (ADR 0001).
